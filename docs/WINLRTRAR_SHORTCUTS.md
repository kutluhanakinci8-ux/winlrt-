# Lertiva Arc — klavye kısayolları (G4)

WinRAR / WinZip tarzı masaüstü kısayolları. Uygulama içinde **?** veya **Kısayollar** sekmesi ile aynı liste açılır.

| Tuş | İşlem |
|-----|--------|
| Ctrl+O | Arşiv seç |
| Ctrl+L | Listele |
| Ctrl+T | Bütünlük testi |
| Ctrl+E | Seçili girdiyi tek dosya olarak çıkar (ZIP / .wlrt) |
| Ctrl+F | İçerik listesinde ara |
| Ctrl+1 | Arşiv sekmesi |
| Ctrl+2 | Geçiş sihirbazı sekmesi |
| ? | Kısayol penceresi |
| Esc | Kısayol penceresini kapat |

**Not:** RAR/7z için tek dosya çıkarma ve metin önizleme sonraki sprintlerde genişletilebilir.
