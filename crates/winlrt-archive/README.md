# winlrt-archive

winlrtRAR / winlrtZIP ortak Rust motoru.

## Geliştirme

```bash
cargo build -p winlrt-archive
cargo run -p winlrt-archive -- --help
```

## Faz 1 durumu

- ZIP: `list`, `extract`, `create`, `test`
- `.wlrt`: iskelet (yakında)
- RAR açma: **Faz 2**
